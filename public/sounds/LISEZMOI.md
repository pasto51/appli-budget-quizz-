# Sons personnalisés (optionnel)

Par défaut, tous les cris et bruitages sont fabriqués par le navigateur : aucun fichier n'est nécessaire.

Pour remplacer un son par un vrai enregistrement, déposez ici un fichier `.mp3`, `.ogg`, `.wav` ou `.m4a` portant le nom du son. Il sera utilisé à la place du son synthétique.

Utilisez uniquement des sons **libres de droits (CC0)** ou enregistrés par vous.

| Fichier | Quand |
|---|---|
| `coq`, `canard`, `grenouille`, `vache`, `cochon`, `mouton`, `chevre`, `ane`, `chat` | Cri de l'équipe qui buzze |
| `good` | Bonne réponse |
| `bad` | Mauvaise réponse |
| `twist` | Règle bizarre |
| `round` | Début de manche, tirage d'un défi ou d'une pub |
| `burger` | Début du Burger de la mort |
| `fanfare` | Podium, menu complet |
| `reveal` | Révélation Sel ou Poivre |
| `tick` | 5 dernières secondes d'un chrono |
| `timeup` | Fin d'un chrono |
| `pop` | Choix verrouillé, vote reçu |

Exemple : `public/sounds/coq.mp3`.
